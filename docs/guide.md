## Running Int2Int on LCGs

### `Generator` base class
The `generators.py` file has the Abstract Base Class `Generator`. Any class that inherits from `Generator` must implement the `generate` and the `evaluate` methods. 

- The abstract method `generate(self, rng)` is expected to generate a single input-output pair for the model. The parameter `rng` is a random number generator object used to ensure the reproducibility of the generated data. It returns the `(input, output)` tuple where input is the problem statement and `output` is its corresponding solution.
- The abstract method `evaluate(self, src, tgt, hyp)` is to evaluate a model's hypothesis against the true target. The parameters are as follows:
* `src` the input sequence.
* `tgt` the target output sequence.
* `hyp` the hypothesis generated by the model.
It is expected to return a tuple containing the evaluation metrics (eg, a score and potentially lists of correct and incorrect predictions).

### `Sequence` subclass 
For example the class `Sequence` inherits the class `Generator` and provides concrete implementations for generating and evaluating data on sequence based mathematical operations.

- `operation` with `maxint`, `minint`, `dims`, `modulus` as other parameters.
- Function `integer_loguniform_sequence` generates a sequence of length `len` integers from the log normal distribution, with the specified `rng` random number generator.
- Function `integer_sequence` generates a sequence of length `len` between `minint` and `maxint` from the uniform distribution.
- Function `integer_matrix` generates a matrix of dims `n` by `p` from uniform distribution between `-maxint` and `maxint`.
- Function `generate` is the most comprehensive and we detail is below.
The purpose is to generate `problem-solution` pairs based on the `self.operation`. It uses the helper methods `integer_sequence` and `integer_matrix` to create inputs and then computes the corresponding outputs. 
The operations `function_simplify` and `fraction_round` aim to generate input-output pairs to teach the transformer how to simplify fractions and how to read mixed fractions and round down.
